บันทึกความชื้นในอาคาร

เปรียบเทียบความชื้นและอุณหภูมิภายในอาคารกับข้อมูลสภาพอากาศภายนอกจาก Open-Meteo API ไม่อนุญาตให้นำข้อมูลไปใช้ก่อนได้รับอนุญาตจาก น.ส.กนกวรรณ จันทร์เกตุ

ก่อนใช้งาน: ให้นำ URL ของ Google Apps Script Web App ที่ Deploy ล่าสุด และ ลงท้ายด้วย /exec ไปใส่ในตัวแปร API_URL ใน JavaScript ด้านล่าง และติดตั้ง Code.gs ที่รองรับ API ตามสัญญาข้อมูลของไฟล์นี้ หากยังไม่ได้ตั้งค่า API เว็บจะทำงานในโหมดทดลองภายในเบราว์เซอร์ และข้อมูลจะไม่แชร์กับผู้ใช้คนอื่น

บันทึกค่าความชื้นภายใน

ภายนอก (Open-Meteo) ภายในสูงกว่าเกณฑ์ ภายในไม่เกินเกณฑ์ เกณฑ์อ้างอิง 60%

ตั้งค่าอาคารและเกณฑ์อ้างอิง

ค่าเริ่มต้น: Latitude 13.8117793, Longitude 100.4876223 และตำแหน่งวัด “ชั้น 14 ท.102” เกณฑ์ 60% เป็นค่าอ้างอิงที่ปรับได้ ไม่ใช่การวินิจฉัยความเสี่ยงต่อสุขภาพ

แสดงข้อมูลล่าสุดไม่เกิน 100 รายการที่อ่านจาก API ปุ่มลบและล้างข้อมูลส่วนกลางไม่ได้เปิดให้ใช้งาน เพื่อป้องกันการลบข้อมูลย้อนหลังโดยไม่ตั้งใจ
